1. Architecture document

Alnomic is one product with two tightly linked AI sections. The emotional layer reads intent, stress, preferences, history, and communication style. The agent layer receives a structured brief and executes practical tasks with tool access, templates, code generation, and human approval checkpoints.

  • Client apps: responsive web, iOS, and Android share the same conversation, project, memory, and billing APIs.
  • Orchestration: a router sends each request through safety, memory retrieval, emotional-state analysis, task planning, tool execution, and final response composition.
  • Memory: profile facts, interaction patterns, project assets, and consented emotional signals are stored separately with user controls.
  • Integration points: model providers, vector search, code sandboxes, resume exporters, design preview services, payments, analytics, and enterprise identity.

Data flow

  1. User sends message, voice note, upload, or mobile action.
  2. Safety and jailbreak detector classifies risk without derailing normal work.
  3. Emotional AI creates an empathy brief: mood, goal, confidence level, and preferred response tone.
  4. Agent AI converts the brief into tasks, artifacts, code, documents, or workflows.
  5. Unified responder returns one coherent answer with previews, choices, and next steps.
  6. Memory service saves only approved long-term learnings and project state.

2. Feature specifications

Emotional & mental intelligence

Understands emotional cues, cognitive patterns, decision friction, motivation, and likely bias. It never diagnoses or replaces care; it supports reflection, planning, communication, and emotionally aware productivity.

Idle evolution: background jobs summarize sessions, improve personalization, detect stalled goals, and prepare helpful suggestions when the user returns.

Agent AI execution

Builds web apps, websites, frontend components, design specs, resumes, cover letters, portfolio pages, and task plans. It asks clarifying questions when requirements are ambiguous and shows previews before high-impact actions.

Limits: it cannot guarantee hiring, legal compliance, medical outcomes, or production security without review.

Shared behavioral rules

The two sections act as one. Emotional context shapes task execution, and execution results feed back into emotional support. Jailbreak attempts are acknowledged with light humor, clear boundaries, and safe redirection.

3. UI/UX design specification

Design language

  • ChatGPT-inspired layout: clean threaded conversations, strong input/output separation, persistent composer, artifact side panels, and clear conversation history.
  • Liquid glassmorphism: frosted cards, translucent navigation, layered blur, soft borders, and depth shadows over calm gradients.
  • Alnomic brand: dark wordmark, blue accent dot, and a circuit-weave logo using blue, teal, orange, and red nodes.
  • Mobile: bottom composer, collapsible project drawer, thumb-friendly controls, and swipeable artifacts.

Motion system

Motion borrows the smooth, spatial feel of modern 3D sites: cards float subtly, panels slide with depth, status changes morph, and generated artifacts appear as layered surfaces. Animation must clarify navigation, loading, confidence, and task state—not decorate every interaction.

4. Business model overview

  • Free: limited conversations, basic emotional check-ins, simple resume drafts.
  • Pro: deeper memory, app generation, portfolio builder, export tools, and priority models.
  • Team: shared workspaces, brand kits, review flows, admin controls, and project templates.
  • Enterprise: SSO, compliance controls, private deployment options, analytics, and custom agents.

Market position

Alnomic sits between personal AI companion, productivity agent, and digital creation studio. Value comes from reducing emotional friction and turning intent into deliverables inside one continuous relationship.
